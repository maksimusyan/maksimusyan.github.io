У всех паролей по краям будут убраны
символы, которые трудно выделить
курсором мыши.
Эта настройка помогает избежать ошибок
при копировании и передаче пароля
Эта настройка помогает избежать ошибок
при сохранении пароля в Excel-таблицу,
где первый символ используется в формулах
У всех паролей будут убраны символы,
которые можно спутать с некоторыми
другими символами.
Эта настройка помогает избежать ошибок
при чтении пароля с бумаги или при
использовании различных шрифтов.
Пример похожих символов: Il!10O
По умолчанию, для генерации используется
криптографически сильный генератор
случайных чисел (window.crypto).
Эта настройка позволяет использовать
резервный метод генерации на основе
метода Math.random(), что делает
итоговую строку более предсказуемой
(снижается безопасность пароля)
Используется менее безопасный способ генерации.
Объект "window.crypto" не доступен в вашей системе.
